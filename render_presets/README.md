# Render Presets (extension)

Sidebar tab **Render Presets** (3D Viewport, N panel): one **Render Presets** card: status (what is applied), the preset dropdown (**Built-in** and **Saved** headings), Apply / Revert / Delete (saved presets only), then **Changes** (with a Compositor row), **Setup** for a built-in (or **Look** for an applied saved preset) and a closed **Save Current as Preset** section (tick groups).

- Built-ins (Draft, Preview, Final, Animation, Ref Sheet) live in `builtin_presets.py` (one option table drives the Setup properties, its rows and the `--option` parser). **Setup** (per scene, `setup_props.py` / `setup_ui.py`): Quality / Speed / Look / Output; where a built-in leaves a value alone it shows Keep / On / Off or a Keep toggle; Reset to Defaults; Save as My Preset (setup + live Look values).
- **Look** (`look_ui.py`, `look_nodes.py`): Polish / Fog / Lens / Film, each with On (takes an Apply: "Apply to add Fog"), Start With (starting looks from the Scripts folder's `*_presets.py`) and live sliders that draw the applied chain's node inputs (found by node label). Fog: Fog Marks rows (`fog_marks.py`), Fog Colour + Sample World (Background colour, else the environment image's average); inputs a mark drives show "from mark". Cycles' viewport has no depth pass: render once (F12), then tweaks re-composite.
- A preset's optional `"look": {group: {input: value}}` is written after the starting looks (older files load as before). Every Apply / Revert calls `fog_marks.rebuild_drivers` (in `preset_store.py`, so the headless script gets it too).

- Saved presets are JSON in the folder set in the add-on preferences (default `~/Blender/RenderPresets`). Built-in presets live in code, so nothing is bundled as files.
- Format: `{"name": ..., "groups": [color|output|cycles|eevee], "settings": {"scene.cycles.samples": 64, ...}}`. Paths start at `scene` (the camera works too: `scene.camera.data.dof.use_dof`). Paths missing in a scene are skipped.
- Compositor: an optional `"compositor_chain": ["Render Polish", ...]` (+ `"compositor_presets": {"Film Look": "Subtle"}`) builds Render Layers > chain > Group Output + Viewer from the Library node groups (`compositor_chain.py`; Depth Fog turns the Z pass on and feeds it). **Fancy** = Final's settings + Render Polish; **Fancy Full** = + Depth Fog, Lens Effects (Clean), Film Look (Subtle). A scene that already has compositor nodes gets a confirmation ("replaces the current compositor, N nodes") and the chain replaces it (scripts and `apply_preset.py` replace without asking); switching presets just swaps the chain. The old tree is kept (fake user) and Revert puts it back; otherwise Revert removes exactly what was added. Render Polish's Lines input is left unconnected.
- Revert: the first apply stores the old values on the scene (`render_presets_revert`); one Revert goes back to before all applies.
- Code: `render_settings.py` is a synced copy of `Addons/shared_addon/render_settings.py` (also used by `batch_tools/apply_render_defaults.py`). Edit the source, run `shared_addon/sync_shared.py`.
- Headless: `blender -b file.blend -P apply_preset.py -- --preset Fancy [--dir <folder>] [--save]`.
- Build: `Addons/package.sh render_presets` (zip into `dist/` and `~/Downloads`). Test: `tests/run_tests.sh` (no renders).
- Not built yet: Scene Kit fold-in, Mood Lighting, special keys (Line Art, Render Polish on/off).
