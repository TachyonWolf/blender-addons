# Digit's Blender add-ons

Add-ons for Blender 5.3 and newer. Each has its own page:

- [Digit's Assorted Tools](digits_assorted_tools/README.md): rigging, scene setups and checks
- [Digit's Modifiers](digits_modifiers/README.md): Geometry Nodes modifiers
- [Digit's Processes](digits_processes/README.md): multi-step jobs
- [Digit's VR](digits_vr/README.md): posing in VR (in development)
- [Render Presets](render_presets/README.md): render settings to save and reuse

**Install:** run `./package.sh` (needs `blender` on your PATH), then in Blender use Preferences > Get Extensions > Install from Disk on the zips it puts in `~/Downloads`.
